# 项目总览：个人静态网站

> 这是项目的「施工总说明」。所有页面、样式、脚本都必须遵守本目录下的文档，
> 避免后期写着写着跑偏。改动方向前，先回来读这里。

## 这是什么

一个**零构建、纯原生**的个人网站。不使用任何静态站点生成器（Hugo / Jekyll / 11ty / Vite 等），
直接手写 **HTML / CSS / JavaScript**。

## 为什么这么做（核心约束）

1. **对照源码学前端**：你（用户）会一边看渲染效果、一边 F12 看源码来学前端。
   如果用生成器，浏览器里看到的是「编译后」的 HTML，根本看不到 `{{ }}` 模板，
   源码和页面隔了一层，反而干扰学习。**纯静态 = 写什么就看到什么。**
2. **双击即开**：纯静态文件不需要本地服务器、不需要 `npm install`，浏览器直接打开就能跑。
3. **零运维**：仓库即站点，GitHub Pages 直接 serve，没有构建链要维护。

## 定位

通用**全栈开发者**个人站，**不绑定**任何特定技术标签（之前考虑的「嵌入式」标签已弃用）。
页面集合（标准 9 页 + RSS + 搜索，详见 architecture.md）：

- 首页 / 博客列表 / 文章详情 / 项目 / 关于 / 装备 / 近况 / 友链 / 404
- 博客：**本地写 Markdown** → 仓库内小脚本生成静态页（见 spec.md 第 8 节）
- **中英双语**：UI 字典切换，预留扩展其他语言
- **4 种视觉皮肤可切换**（默认工程仪器风），见 spec.md 第 1 节

## 关键决策摘要

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 技术栈 | 原生 HTML/CSS/JS，零构建 | 利于对照源码学前端（见上） |
| 站点生成器 | 不用（Hugo 等已弃用） | 模板语法在浏览器不可见 |
| 博客形态 | 本地写 `.md` → `tools/build.mjs` 生成静态页 + 刷新 `posts.js` | 写作体验好，产物仍为零依赖静态页 |
| 文章详情 | 构建脚本生成 `blog/<slug>.html`（纯静态 HTML） | 双击可看、源码可读 |
| 视觉风格 | **4 种可切换皮肤**（instrument / minimal / terminal / magazine） | 随时换风格，不用纠结；详见 spec.md |
| 国际化 | UI 字典切换（zh/en），预留扩展 | 加语言只加一个字典 |
| 注释标准 | 教材级（解释 **why**，不写废话） | 你对照学习 |
| 部署 | GitHub Pages（纯静态 Actions 工作流） | 仓库即站点 |
