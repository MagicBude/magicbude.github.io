# 项目愿景

## 一句话定位

一个持续生长的个人数字基地：用真实作品证明能力，用长期记录沉淀思考，并成为未来网站和工具的稳定入口。

## 为什么存在

这个网站首先服务于所有者本人。它帮助整理项目、记录成长、复习前端知识并串联其他作品。当内容逐渐积累后，也应帮助陌生人快速认识 magicbude，而不依赖社交平台的时间线。

## 目标用户

1. 网站所有者：维护资料、复习源码、发布内容、串联项目。
2. 同行与学习者：阅读文章、查看实现与学习原生前端。
3. 未来的合作方或朋友：快速理解能力、兴趣与真实联系方式。

## 希望留下的印象

- 真实：不包装不存在的经历。
- 好奇：愿意跨领域探索并公开学习过程。
- 扎实：代码、文档、交互和细节经得起检查。
- 有趣：技术之外保留个人气质，网站值得探索。

## 非目标

- 不做需要账号、数据库或服务端业务的社区产品。
- 不为了炫技加入无法解释其价值的功能。
- 不把个人站伪装成成熟公司的营销站。
- 不为了消除少量 HTML 重复而引入整站生成架构。
- 不把阶段性的“开发中”或“重建”当作主站长期定位；公开文案应在内容扩展后仍然成立。
