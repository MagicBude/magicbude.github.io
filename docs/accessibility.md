# 可访问性规范

可访问性是默认质量，不是发布后的补丁。

## 结构

- 每页使用正确语言、唯一标题与清晰地标。
- 主内容前提供“跳到主内容”链接。
- 标题不跳级；列表、引用和表格使用对应语义元素。
- 能用原生按钮、链接和表单控件解决时，不重新模拟控件。

## 键盘与焦点

- 所有交互均可通过键盘完成。
- 焦点样式清晰，不能为了视觉效果整体移除。
- DOM 顺序与视觉阅读顺序保持一致。
- 移动菜单的视觉状态必须与 `aria-expanded` 同步。

## 感知与动效

- 正文和控件保持可靠颜色对比度。
- 状态不能只通过颜色表达。
- 信息图片提供准确替代文本，装饰图片使用空替代文本。
- 尊重 `prefers-reduced-motion`，不使用闪烁和无法暂停的持续动画。
- 点击目标适合触摸操作，窄屏下不出现非必要横向滚动。

## 验证

至少进行键盘走查、200% 缩放、320px 窄屏、四套皮肤和中英文切换检查。自动检查只能辅助，不能替代人工验证。
