# 产品需求

本文说明网站要解决什么问题；实现方式以 `docs/development/architecture.md` 的简单原生架构为准。

## 核心页面

- `index.html`：以原创封面建立第一印象，用搜索入口和两列基地总览回答“这是谁、这里有什么”；左栏承载简短身份、当地信息和发布日历，主栏汇总文章与项目；根网址直接进入内容，不设置开屏中转。
- `projects/`：把可访问、持续维护的当前作品与明确标记为规划中的项目分层展示；统计数字从共享项目数据计算，不能用计划冒充成果。
- `blog/`：以真实文章数、标签数和语言数形成写作档案，支持数据驱动筛选；详情页由 Markdown 构建器生成独立元数据、目录与舒适阅读版式。
- `links/`：作为跨设备个人收藏库，集中保存网站、软件工具、参考资料与友链；收藏以紧凑多列卡片展示，并支持按用途分类筛选，换设备后仍能快速找到常用入口。
- `about/`：用配置驱动的身份档案、真实兴趣与建站原则介绍 magicbude，并只展示可验证、路径有效的公开联系方式。
- `search/`：在浏览器本地建立页面、文章、项目、友链、资源与工具的双语索引，支持关键词、内容类型筛选和无查询的分组浏览。
- `404.html`：不只提示地址失效，还展示当前路径，并提供首页、站内搜索与核心栏目的明确恢复入口；无 JavaScript 时保留普通链接。

## 全站能力

- 四套皮肤运行时切换，并记住本机偏好。
- 中文和英文 UI 切换，语言字典便于继续扩展。
- 响应式导航、跳到主内容链接、清晰焦点和减少动效降级。
- JavaScript 失败时保留页面静态说明和普通链接。
- 页面代码与视觉资源不请求第三方运行时；允许为实时功能调用经过评估的外部数据 API。
- 首页文章数、标签数、项目数、主题标签和发布日历必须读取现有共享数据计算，不单独维护易失真的统计值。
- 首页时钟读取访客浏览器本地时间与时区，不依赖后端，也不发送位置数据。
- 首页天气仅在访客主动点击后申请定位；坐标约简后请求 Open-Meteo，不保存位置，拒绝权限或断网时必须优雅降级。

## 博客边界

Markdown 转换器只服务文章写作：读取 `content/posts/*.md`，更新文章详情、列表数据和 RSS。
它不得生成或覆盖主站其他页面、CSS、公共 JavaScript 与文档。

## 内容约束

- 已完成成果、经历、外链和联系方式必须真实可验证。
- 未来项目和栏目可以提前规划，但必须明确标注“规划中”或占位用途，不能伪装成已经完成。
- 示例内容必须标记为教学示例，不能混入公开履历。
- “不伪造、不占位”等维护原则写在文档中，不在公开页面反复自证；界面文案直接介绍内容本身。

## 验收基线

- 直接双击 `index.html` 能完整浏览。
- 外部天气不可用或定位被拒绝时只显示说明，不影响其他页面能力。
- 仅用键盘能操作导航、语言、皮肤、筛选和搜索。
- 320px 宽度与 200% 缩放下核心内容仍可使用。
- 四套皮肤和中英文不会产生不可读或溢出状态。
- 运行 `node tools/audit.mjs` 时，公开 HTML 的结构、可访问名称、重复 ID、站内静态引用和 JavaScript 语法检查全部通过。
