# 产品需求

本文说明网站要解决什么问题；实现方式以 `doc/architecture.md` 的简单原生架构为准。

## 核心页面

- `index.html`：极简开屏与进入主站的明确链接。
- `home.html`：说明“这是谁、这个站有什么、最近更新了什么”。
- `projects.html`：只展示真实存在的项目、职责、状态和可验证链接。
- `blog.html`：展示文章并提供语言和标签筛选。
- `now.html`：记录当前真实近况，不伪造时间线。
- `uses.html`：记录实际使用的软硬件与服务。
- `links.html`：收录真实友链和确实有用的资源。
- `about.html`：说明 magicbude、建站目的和可公开联系方式。
- `search.html`：在浏览器内统一搜索页面、文章、项目、友链与资源。

## 全站能力

- 四套皮肤运行时切换，并记住本机偏好。
- 中文和英文 UI 切换，语言字典便于继续扩展。
- 响应式导航、跳到主内容链接、清晰焦点和减少动效降级。
- JavaScript 失败时保留页面静态说明和普通链接。
- 浏览器端不请求第三方运行时资源。

## 博客边界

Markdown 转换器只服务文章写作：读取 `posts/*.md`，更新文章详情、列表数据和 RSS。
它不得生成或覆盖主站其他页面、CSS、公共 JavaScript 与文档。

## 内容约束

- 已完成成果、经历、外链和联系方式必须真实可验证。
- 未来项目和栏目可以提前规划，但必须明确标注“规划中”或占位用途，不能伪装成已经完成。
- 示例内容必须标记为教学示例，不能混入公开履历。

## 验收基线

- 直接双击 `index.html` 能完整浏览。
- 仅用键盘能操作导航、语言、皮肤、筛选和搜索。
- 320px 宽度与 200% 缩放下核心内容仍可使用。
- 四套皮肤和中英文不会产生不可读或溢出状态。
